# PS2115 - 影视资源自动化聚合与转存系统 🎬

PS2115 是一个专为 **115 网盘**用户打造的影视资源自动化管理工具。集成 Telegram Bot、多源资源聚合搜索、全自动订阅追剧、媒体整理工作流，以及 115 网盘深度整合（STRM 302 三层同步 / WebDAV 虚拟挂载 / ed2k 离线），把「找资源 → 转存 → 整理 → 播放」全流程自动化。

> Go 后端（内嵌前端）+ SQLite 三库，单二进制即可运行。

---

## ✨ 核心特性

### 🔍 多引擎资源聚合
- **CloudSaver**：直接爬取各大 Telegram 公开资源频道，深度接入订阅系统。
- **Pansou**：独立聚合搜索引擎 API，全网泛搜，支持直接转存 / 离线下载。
- **聚合磁力**：磁力猫 / 海盗湾 / BitSearch 多引擎并行检索、跨引擎去重合并；支持来源标记、关键词过滤、数据来源开关，**抓取深度可配置**（系统设置里改，即时生效）。
- **Sidhub / JAV18**：Sidhub 115 离线抓取、内置 JAV18 番号库搜索。

### 🤖 Telegram Bot
- **多引擎直搜**：`/search` / `/cs` / `/ps` / `/av` 在 Telegram 内直接搜索，结果卡片内联按钮「类型展开 / 详情翻页」。
- **一键离线**：磁力 / JAV18 / Sidhub 类结果带「📥 离线下载」按钮，直接提交 115 离线到指定目录。
- **富推送**：订阅更新、动漫新资源自动推送（附离线按钮）。
- **防误触排版**：链接以文本展示便于复制，按钮布局防误触。

### ⚡ 115 深度整合与防风控
- **STRM 302 三层同步**：
  - **L1 实时事件**：115 生活事件增量监控，精准捕获文件变动；
  - **L2 间隔巡检**：定期比对目录 Hash 兜底；
  - **L3 全树 Sweep**：全树扫描（大库慎开，防风控）。
  - 支持**多监控根**，每根独立闭环（索引 / 指纹 / 输出目录 / 推送全部按根隔离）。
- **防风控**：可控 QPS 节流 + 抖动、分页扫描、目录树血缘校验、播放器 UA 前缀智能缓存（大幅减少 302 请求频率）。
- **转存全能**：分享转存支持保留目录结构、分页全量转存、同名文件三策略（跳过 / 自动改名 / 覆盖洗版）；同批同目录去重、真实变更判定（未变化不计更新、不入推送）。
- **ed2k 支持**：搜索侧识别 ed2k 链接（离线 / 复制）；订阅侧「同时接收 ED2K 资源」开关 —— ed2k 走 **115 离线下载**落到该订阅自己的转存目录，与 115 转存可混合（同一集只保留一份，先到先得）。
- **115 运维**：自动签到（Cron 可配）、云下载清空、删除任务 / 回收站任务定时化。

### 📺 媒体整理与自动化
- **媒体规则**：8 类规则自由编排 —— 整理 / 命名 / TMDB 命名 / TMDB 整理 / 转移 / 删除 / 工作流 / 自定义流程，支持 Cron 定时与手动执行。
- **TMDB 整理**：剧集模式（tmm 风格目录规范化「剧名 (年份) {tmdb-ID}」+ Season 归类）、电影模式（扁平化 + 清理空目录），支持归档。
- **媒体匹配**：TMDB × Emby 双向匹配、探索页海报直点匹配、已入库校验、质量评分。
- **订阅系统**：多来源订阅自动追剧、动漫 RSS 订阅与自动点阅、转存历史全程留痕（含资源类型标签）。

### 🌐 WebDAV 虚拟文件系统（实时挂载）
- 115 网盘目录（支持**多挂载点**）实时映射为 WebDAV，**不落盘**：目录实时拉取 115，视频文件按需 302 到直链。
- **占位形态开关**：
  - `STRM 模式`（默认）：视频显示为 `.strm` 文本文件，适配 Emby / Infuse 等识别 STRM 的客户端；
  - `视频占位模式`：视频显示为**原始扩展名**（`.mp4` / `.mkv`），播放时服务端直接 302 到 115 直链 —— **适配不识别 .strm 的客户端**；切换时自动隐藏同名原生 .strm，避免双版本。
- 配置全在 Web UI（挂载点 / 端口 / 凭据 / 缓存 TTL / 扩展名白名单），保存即热重启该端口，不影响主服务。

### 🤖 AI 能力（OpenAI 兼容接口）
- **AI 一键生成命名正则**：给一个示例文件名，自动产出可用的正则 + 重命名表达式。
- **AI 翻译片名**：翻译资源标题辅助 TMDB 匹配。
- **连通性测试**：设置页一键验证 BaseURL / API Key / 模型。

### 🚀 架构与安全
- 后台 Cron 定时拉取 + 前端 API 手动触发双引擎；目录缓存 TTL + 上限淘汰 + 过期兜底。
- SQLite 三库（主库 / JAV18 / ed2k）+ WAL，纯 Go 驱动（modernc），零 CGO。
- 单二进制内嵌前端（`go:embed`），部署 = 一个可执行文件 + 一个数据目录。
- JWT 鉴权、配置脱敏模板、镜像零凭据、日志自动轮转。

## 🎬 支持的播放方式

| 方式 | 说明 |
| --- | --- |
| **Emby / Jellyfin（STRM 302 · 推荐）** | 把 STRM 输出目录添加为媒体库即可自动刮削；播放器经 UA302 反代端口（默认 `:8099`）接入，STRM 请求被拦截并 **302 到 115 CDN 直链** —— 服务端零流量、直链按播放器 UA 缓存、拖进度条流畅 |
| **WebDAV 挂载** | 任意 WebDAV 客户端直连 `:15222` 挂载播放：Infuse / VidHub / Fileball / PotPlayer / Nova Video Player / Windows 资源管理器等（详见「WebDAV 虚拟文件系统」） |
| **ed2k 点播** | ed2k 批量生成的 STRM 播放时自动提交 115 离线下载并轮询出直链；未入库的链接播放即自动登记，之后秒开 |
| **浏览器直接打开** | 用浏览器打开播放地址时自动走「代理 CDN 内容」通道（带 CORS），可在浏览器中直接播放 |

## 📦 快速部署

### 1. 编写 `docker-compose.yml`

```yaml
services:
  ps2115:
    image: lisylva/ps2115:latest
    container_name: ps2115
    restart: unless-stopped
    ports:
      - "8080:8080"     # Web UI / API
      - "8099:8099"     # UA302 反代端口（播放器经它访问 Emby 时拦截 STRM → 302 直链；不用可删）
      - "15222:15222"   # WebDAV 虚拟文件系统（改端口记得同步这里）
    volumes:
      - ./data:/app/data
      - ./strm:/app/strm
      - ./config.yaml:/app/config.yaml
    environment:
      - TZ=Asia/Shanghai
      - GOMEMLIMIT=1600MiB       # 防 Go 堆无上限增长被 OOM Kill
    logging:
      driver: json-file
      options:
        max-size: "10m"          # 日志轮转：单文件 10MB × 5 个
        max-file: "5"
    mem_limit: 2g
    cpus: 2.0
```

> `./strm` 是 STRM 输出落盘目录（容器内 `/app/strm`）；WebDAV 是纯实时视图，无需额外映射。

### 2. 准备配置文件

在映射目录创建 `config.yaml`（完整配置项以项目内 `config.default.yaml` 为准）：

```yaml
# 基础服务配置（server 段为登录凭据，必填）
server:
  port: 8080
  username: admin
  password: "CHANGE_ME"                # ⚠️ 务必修改
  jwt_secret: "CHANGE_ME"              # ⚠️ 务必改成随机串（保持默认 = 任何人可伪造管理员令牌）

# WebDAV 段：可选 —— 仅作首次启动的种子值。部署后在
# 「系统设置 → WebDAV 虚拟文件系统」里配置即可（保存写入数据库、优先于本文件；
# 之后本段不再回读，整段注释掉也不影响已配置好的实例）
webdav:
  enabled: true
  port: 15222
  username: admin
  password: "CHANGE_ME"                # ⚠️ 务必修改
  mount_dir: "0"                       # 0 = 根目录，或填你的目录 CID（旧版单挂载点字段，启动时自动迁移成 mounts）
  redirect_base_url: "http://<你的IP>:8080"  # 空 = 按请求 Host 推导；需填播放器能访问到的地址
  cache_ttl: 300
  page_size: 1150
  debug_log: false

# CloudSaver：爬 Telegram 公开频道（作用于「搜索资源」+ 订阅系统）
cloudsaver:
  channels:
    - id: "QukanMovie"                 # 频道 ID（t.me/s/<id> 里的那段）
      alias: "115影视资源分享频道"      # 显示名
    # ... 可继续添加

# Pansou 聚合搜索 API（独立搜索页，不接入订阅）
pansou:
  url: "https://so.252035.xyz/"

# 聚合磁力引擎（列表驱动，并行检索合并去重；域名失效换新即可）
magnet:
  sources:
    - name: 磁力猫
      type: clm
      url: "https://clm64.top/"
      enabled: true
    - name: 海盗湾
      type: apibay
      url: "https://apibay.org/"
      enabled: true
    - name: BitSearch
      type: bitsearch
      url: "https://bitsearch.eu/"
      enabled: true
```

> `server` 段为登录凭据（安全起见必须修改 `password` / `jwt_secret`），其余段均为可选。
> 部署后绝大多数设置可在 **Web UI → 系统设置** 里修改并即时生效（数据库值优先于本文件）；
> **WebDAV 整段均可由 UI 管理**（本文件里仅作首次种子，配置好后注释掉不影响）；
> 需要落在本文件（改后重启生效）的只有：`server` 段、CloudSaver 频道列表、Pansou URL、聚合磁力引擎列表。

### 3. 启动

```bash
docker compose up -d
# 访问 http://<你的IP>:8080 登录
```

### 常用操作

**① 分享链接批量生成 STRM（分享源入库）**

适用：把别人的 115 分享链接转成本地媒体库的 STRM 文件。

1. 【STRM&302 → 分享批量生成】粘贴 115 分享链接，填「STRM输出目录」与「服务地址」（播放器能访问到的 PS2115 地址，如 `http://<你的IP>:8080`；若 Emby 播放走 UA302 反代（:8099）则填 `:8099`）；
2. 直接点「生成 STRM 文件并写入磁盘」一次性解析并写入（自动保留分享原目录结构）；
3. 或先点「扫描入库」把分享内容存入本地索引（之后生成无需再请求 115 API），再从列表逐条点「生成」。

**② 网盘目录批量生成与增量同步（个人盘入库）**

适用：把自己 115 网盘的指定目录同步为本地 STRM，并保持自动增量更新。

1. 【STRM&302 → 网盘批量生成】用「＋ 添加监控根（选115目录）」添加目录（CID + 独立输出目录）→「保存监控根」；
2. 点该行「扫描」做一次全量扫描建立基线（或「一键扫描全部监控根」）→ 点「逐根导出 STRM」写盘；
3. **定时增量**：在「保存定时任务」处配置（⚠️ 新增根后必须先建基线，否则该根存量文件不会被索引）；
4. **L2 间隔巡检**（三层防护体系）：建议启用（对漏掉的变动兜底）；**L3 全树 Sweep**：⚠️ 大库不建议开启（易触发 115 风控），日常靠 L1 + L2 已足够；
5. 本地多余 STRM 可先「预演清理多余STRM」（只读清单）核对后再执行清理。

**③ WebDAV 挂载**

1. 系统设置 →「WebDAV 虚拟文件系统」→ 配置挂载点（支持多目录）、占位形态、扩展名白名单；
2. 客户端连接 `http://<你的IP>:15222`（任意 WebDAV 客户端，如 Infuse、PotPlayer）；
3. **客户端不认 `.strm` 时**，把占位形态切到「视频占位模式」—— 文件名显示为原扩展名，播放时服务端直接 302 到 115 直链；
4. 切换开关或改挂载点后，已挂载的客户端需**重新挂载 / 刷新**以更新目录缓存。

## 🔧 常见问题

**Q：播放器播放不了（Emby / WebDAV 都算）？**
排查三样：
1. `redirect_base_url` 是否填写了**当前实际可访问的地址**（服务器 IP 变过会失效）；
2. WebDAV 挂载点 CID 是否仍有效（挂到已失效 / 空目录 = 什么都看不到）；
3. WebDAV 换模式 / 换挂载点后，客户端**重新挂载**刷新缓存。

**Q：订阅收不到 ed2k 资源？**
订阅编辑里打开「同时接收 ED2K 资源」（默认关）。ed2k 不能转存但能**离线下载**，落点为该订阅自己的转存目录；同一集只保留一份（先到先得）。

**Q：搜到资源但订阅用不上？**
确认该频道在 `cloudsaver.channels` 里，且消息带网盘 / ed2k 链接（纯资讯、预告类消息会被过滤掉）。

**Q：为什么全树 Sweep 不建议开？**
L3 全树扫描文件量巨大，极易触发 115 风控限速。日常靠 L1 实时事件 + L2 间隔巡检已能保持高度一致。
