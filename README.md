# PS2115 - 影视资源自动化聚合与转存系统 🎬

PS2115 是一个专为 115 网盘用户打造的影视资源自动化管理工具。它集成了强大的 Telegram Bot 交互、多源资源聚合搜索、全自动订阅追剧以及 115 网盘的深度本地化管理（包含增量同步与事件监控）。

## ✨ 核心特性

* **🤖 极致的 Telegram Bot 交互**：采用高屏效比设计，防误触 URL 按钮排版，实现极简的搜索、转存、订阅体验。
* **🔍 双引擎资源聚合**：
* `CloudSaver`：直接抓取各大 Telegram 公开资源频道，深度接入自动订阅系统。
* `Pansou`：独立聚合搜索引擎 API，提供全网泛搜（仅用于直接转存/离线，无缝补充资源库）。


* **⚡ 115 深度整合与防风控**：
* 内置 115 生活事件增量监控，支持特定 CID 的精准捕获与目录树血缘校验。
* 适配 115 最新 Pro API 加密与解密逻辑（解决 `decode fail!` 报错）。
* 严格且安全的 QPS 控制（动态节流至 0.5 - 1.0），保护账号免受风控。


* **🚀 高性能架构**：后台 Cron 定时拉取与前端 API 手动触发双引擎策略；针对播放器设计的 UA 前缀智能缓存机制（大幅减少 302 重定向请求频率）。

## 📦 快速部署 (Docker)

推荐使用 Docker Compose 进行一键部署。

### 1. 编写 `docker-compose.yml`

```yaml
version: '3.8'

services:
  ps2115:
    image: lisylva/ps2115:latest # 或指定固定版本号
    container_name: ps2115
    restart: unless-stopped
    ports:
      - "8080:8080" # Web UI / API 端口
      - "8099:8099" # 内部通信/中间件反代端口
      - "15222:15222" # web端口需在config.yaml配置
    volumes:
      - ./data:/app/data
      - ./strm:/app/strm
      - ./config.yaml:/app/config.yaml
    environment:
      - TZ=Asia/Shanghai

```

### 2. 准备配置文件

在映射的目录下创建 `config.yaml`，参考以下配置：

```yaml
# 基础服务配置
server:
  port: 8080                        #web进入端口
  username: admin
  password: admin123
  jwt_secret: ps2115-secret-key-change-me
webdav:
  enabled: true
  port: 15222
  username: admin
  password: admin123
  mount_dir: "3140139588359750069"              # 0=根目录，或指定某个 CID
  redirect_base_url: "http://x.x.x.x:xxxx"       # 空=自动拼接 http://localhost:8080 如果docker的环境变量 xxxx:8080即填 xxxx
  cache_ttl: 300              # 目录缓存 5 分钟

# CloudSaver （接入订阅系统）
cloudsaver:
  channels:
    - id: "xxxx"
      alias: "影视频道名称"


# Pansou 聚合搜索 API：独立搜索引擎（用于临时搜索及转存，不接入订阅）
pansou:
  url: "https://so.252035.xyz/"

```

### 3. 启动服务

```bash
docker-compose up -d

```

## 📱 Telegram Bot 交互指南

绑定并启动 Bot 后，你可以通过以下命令在 Telegram 中直接管理你的媒体库：

| 命令 | 参数 | 说明 |
| --- | --- | --- |
| `/search` | `<关键词>` | 搜索 115 资源（走 Cloudsaver 引擎，支持订阅联动） |
| `/ps` | `<关键词>` | 盘搜搜索（走 Pansou 引擎，支持直接转存/离线下载） |
| `/sub add` | `<关键词> | <目录>` | 添加新的追剧订阅规则 |
| `/sub list` | 无 | 查看当前所有订阅任务的状态 |
| `/sub del` | `<ID>` | 删除指定的订阅 |
| `/sub pause` | `<ID>` | 暂停指定的订阅任务 |
| `/sub resume` | `<ID>` | 恢复已暂停的订阅任务 |
| `/sub check` | `<ID>` | 立即触发一次订阅检查，拉取最新资源 |
| `/status` | 无 | 查看系统运行状态、资源占用及 QPS 监控 |
| `/cookie` | `<cookie>` | 快速更新或重置 115 网盘的 Cookie 凭证 |
| `/help` | 无 | 显示使用帮助与命令列表 |

## ⚙️ Web UI 操作指南

通过 Web 界面，你可以更直观地管理 115 分享链接、个人网盘目录，并生成 Emby/Jellyfin 兼容的 STRM 播放文件。以下是两项核心功能的操作说明：

### 一、 分享链接批量生成 STRM (分享源入库)

*适用场景：将别人分享的 115 链接直接转化为本地媒体库的 STRM 文件。*

#### 1. 参数配置

* **STRM 输出目录**：填写容器内的映射路径。例如你的 Docker 映射为 `./strm:/strm`，建议此处填写 `/strm/分享` 以便分类存放。
* **服务地址**：填写供播放器（如 Emby）反代访问中间件的地址。格式通常为 `http://<你的IP>:8099`（系统默认端口为 8099，若未修改保持原样即可）。

#### 2. 执行步骤

1. **扫描入库（第一步）**：在【分享索引管理】中贴入带有密码的 115 分享链接，点击 `[扫描入库]`。此操作会将分享内容安全地抓取至本地数据库缓存。
2. **生成文件（第二、三步）**：
* **单项生成**：在下方的入库列表中，找到对应的分享记录，点击右侧绿色的 `[生成]` 按钮。
* **批量生成**：或者点击上方全局的 `[生成 STRM 文件并写入磁盘]` 按钮。



---

### 二、 网盘目录批量生成与增量同步 (个人盘入库)

*适用场景：将自己 115 网盘内的指定目录结构同步为本地 STRM 文件，并保持自动化增量更新。*

#### 1. 基础参数与目录选择

* **基础配置**：与分享链接生成一致，配置好【STRM输出目录】和【服务地址】。
* **选取 CID (步骤 1)**：在【选择 115 网盘目录】区块，点击右上角的刷新按钮，从目录树中精准选取你需要入库的文件夹 CID（如：电影库、剧集库）。

#### 2. 扫盘与写入步骤

* **扫描入库 (步骤 2)**：选定目录后，点击 `[扫描入库(防风控)]`。系统将以防风控的平滑速率将该目录下的文件索引存入 DB 缓存。
* **导入 STRM (步骤 4)**：缓存建立后，点击 `[全量索引导入 STRM]`，系统会将 DB 中的数据正式写入配置好的本地输出目录中。

#### 3. 自动化与防风控策略配置 (核心)

为了保持本地 STRM 与 115 网盘的实时同步，请正确配置自动化策略：

* **定时增量 (步骤 5)**：启用定时增量开关，**请务必确保填写的“定时目录 CID”与你刚刚扫描入库的 CID 完全一致**，也可直接点击 `[使用当前选择]` 快速填入。
* **三层防护体系设置**：
* **间隔巡检 L2 (步骤 6)**：这是实时事件监控的**兜底设置**，建议启用。它会定期比对目录 Hash，捕捉可能漏掉的变动。
* **全树 Sweep L3 (步骤 7)**：**⚠️ 强烈注意**：如果你的 115 网盘总文件库非常庞大，**不建议开启**该选项。全树级别的扫描极易触发 115 风控限制，日常使用依靠实时事件（L1）和间隔巡检（L2）已能保证高度的一致性。
